# M01-T01-ST02-L: Programming vs Programming Language

## 1. What is Programming?

Programming is the process of writing instructions to solve a problem or perform a specific task using a computer.

## 2. What is a Programming Language?

A programming language is a language used to communicate instructions to a computer. It helps programmers write instructions that computers can execute.

## 3. What is Python?

Python is a high-level programming language. It has simple and readable syntax. Python is used in web development, automation, data science, artificial intelligence and many other fields.

## 4. What is Syntax?

Syntax refers to the rules and structure used to write instructions in a programming language. Every programming language has its own syntax rules.

## 5. Programming vs Python

Programming is the process of solving problems by creating logical instructions. Python is a programming language used to implement those instructions.

## 6. What Remained the Same?

The problem-solving logic remained the same. The eligibility conditions did not change when converting the logic into Python code.

## 7. What Changed?

The representation of instructions changed. We used simple English-like statements in pseudocode, whereas Python requires specific syntax, keywords, indentation and operators.

## 8. My Understanding

Programming helps us develop logical thinking and problem-solving skills. Python helps us convert our logic into executable instructions that a computer can understand.

## 9. Can Someone Know Python Syntax but Still Be Weak at Programming? Why?

Yes. A person can know Python syntax but still be weak at programming because programming requires logical thinking, problem-solving skills and the ability to develop step-by-step solutions. Knowing syntax alone is not enough.
